# Query cookbook for the span store

Every recipe here is one the migration oracle runs against Phoenix and the store daily, and
they agree on 75 of 75 across five projects (2026-09-11). The SQL is the typed layout's; a
`source` filter scopes one project so two never blend. Run any of them with

```bash
dal store query "<sql>"                       # configured store, typed layout
dal store query --format json "<sql>"         # for an agent to read
```

Generated by `scripts/render_store_cookbook.py` from `scripts/migration_oracle.py`. Edit the
oracle, not this file.


## 1. How many spans and traces do we hold?

```sql
SELECT count(*)::BIGINT AS spans, count(DISTINCT trace_id)::BIGINT AS traces FROM spans
```

## 2. Spans per day

```sql
SELECT CAST(day AS VARCHAR) AS day, count(*)::BIGINT AS n FROM spans GROUP BY 1 ORDER BY 1
```

## 3. How many calls errored?

```sql
SELECT status_code, count(*)::BIGINT AS n FROM spans GROUP BY 1 ORDER BY 1 NULLS LAST
```

## 4. What kinds of spans are there?

```sql
SELECT name, count(*)::BIGINT AS n FROM spans GROUP BY 1 ORDER BY 2 DESC, 1 NULLS LAST LIMIT 25
```

## 5. Tokens per day

```sql
SELECT CAST(day AS VARCHAR) AS day, sum(coalesce(tokens_prompt,0))::BIGINT AS p, sum(coalesce(tokens_completion,0))::BIGINT AS c FROM spans GROUP BY 1 ORDER BY 1
```

## 6. Prompt cache read and write per day

```sql
SELECT CAST(day AS VARCHAR) AS day, sum(coalesce(tokens_cache_read,0))::BIGINT AS r, sum(coalesce(tokens_cache_write,0))::BIGINT AS w FROM spans GROUP BY 1 ORDER BY 1
```

## 7. Which models, how much?

```sql
SELECT model_name AS model, count(*)::BIGINT AS n FROM spans GROUP BY 1 ORDER BY 2 DESC, 1 NULLS LAST LIMIT 20
```

## 8. Is extended thinking on?

```sql
SELECT thinking_type AS think, count(*)::BIGINT AS n FROM spans GROUP BY 1 ORDER BY 2 DESC, 1 NULLS LAST
```

## 9. Who is active? (per-trace identity)

```sql
WITH ident AS (SELECT trace_id, any_value(account_uuid) AS account_uuid, count(*) AS n FROM (SELECT trace_id, account_uuid AS account_uuid FROM spans) GROUP BY 1) SELECT account_uuid, count(*)::BIGINT AS traces, sum(n)::BIGINT AS spans FROM ident GROUP BY 1 ORDER BY 2 DESC, 1 NULLS LAST
```

## 10. How many sessions?

```sql
WITH ident AS (SELECT trace_id, any_value(session_id) AS session_id FROM (SELECT trace_id, session_id AS session_id FROM spans) GROUP BY 1) SELECT count(DISTINCT session_id)::BIGINT AS sessions, count(*) FILTER (WHERE session_id IS NULL)::BIGINT AS traces_without FROM ident
```

## 11. The errored spans

```sql
SELECT trace_id, span_id FROM spans WHERE status_code = 'ERROR' ORDER BY 1, 2 LIMIT 50
```

## 12. The biggest traces, as parent and child

```sql
WITH top AS (SELECT trace_id FROM spans GROUP BY 1 ORDER BY count(*) DESC, 1 LIMIT 25) SELECT trace_id, span_id, coalesce(parent_span_id,'') AS parent_id, name FROM spans WHERE trace_id IN (SELECT trace_id FROM top) ORDER BY 1, 2
```

## 13. What tools did the agent run?

```sql
SELECT tool_name AS tool, count(*)::BIGINT AS n FROM spans WHERE tool_name IS NOT NULL GROUP BY 1 ORDER BY 2 DESC, 1 LIMIT 30
```

## 14. A deterministic content sample (the oracle's diff sample)

```sql
SELECT span_id, trace_id, name, status_code, strftime(start_time AT TIME ZONE 'UTC', '%Y-%m-%d %H:%M:%S.%f') AS start_time, coalesce(tokens_prompt,0)::BIGINT AS tp, coalesce(tokens_completion,0)::BIGINT AS tc, model_name AS model, md5(coalesce(input_value,'')) AS in_md5, md5(coalesce(output_value,'')) AS out_md5, coalesce(json_array_length(events),0)::BIGINT AS n_events FROM spans WHERE span_id LIKE '%00' ORDER BY 1 LIMIT 500
```

## 15. Autonomy ratio: agent-continued turns versus text turns

```sql
WITH b AS (SELECT strftime(start_time AT TIME ZONE 'UTC', '%Y-%m') AS mon, input_value AS v FROM spans WHERE name = 'litellm_request') SELECT mon, count(*) FILTER (WHERE v NOT LIKE '%redacted-by-litellm%' AND v NOT LIKE '%dal_trim%' AND v LIKE '%tool_result%')::BIGINT AS agent_continued, count(*) FILTER (WHERE v NOT LIKE '%redacted-by-litellm%' AND v NOT LIKE '%dal_trim%' AND v NOT LIKE '%tool_result%' AND v LIKE '%type%text%')::BIGINT AS text_turns FROM b GROUP BY 1 ORDER BY 1
```

## Scoping to one project

Every query above takes `WHERE source = '<name>'` on `spans`; `dal store status` lists the
sources present. The dead `dev-agent-lens` project is 93 percent of May and flips the
autonomy headline when blended with `sf-workspaces`; scope it out or in on purpose.

## Bringing your own Claude folder

```bash
dal ingest-sessions --include '*your-repo*' --project my-claude --to-store --yes
dal store layout typed && dal store verify --from-parquet '<store>/spans_raw/**/*.parquet'
```

Twelve seconds for three weeks of sessions on a laptop. Then any recipe above, scoped to
`source = 'my-claude'`.

## Splitting by harness (Claude Code, Codex)

`agent` names the harness that wrote a session: `claude-code` or `codex` for sessions loaded
from files, NULL for proxy traffic (which is Claude Code today). `tool_kind` puts every
harness's tools in one vocabulary (`shell`, `edit`, `read`, `search`, `plan`, `mcp`, ...), so
`Bash` and Codex's `exec_command` count as the same thing. Load Codex sessions with:

```bash
dal ingest-sessions --agent codex --include '*your-repo*' --project my-codex --to-store --yes
```

Tokens and cache by harness:

```sql
SELECT COALESCE(agent, 'claude-code (proxy)') AS harness, count(*) FILTER (WHERE span_kind = 'LLM')::BIGINT AS llm_calls, sum(tokens_prompt)::BIGINT AS prompt, sum(tokens_cache_read)::BIGINT AS cache_read, sum(tokens_completion)::BIGINT AS completion FROM spans GROUP BY 1 ORDER BY 2 DESC
```

What each harness spends its tool calls on:

```sql
SELECT COALESCE(agent, 'claude-code (proxy)') AS harness, tool_kind, count(*)::BIGINT AS n FROM spans WHERE tool_kind IS NOT NULL GROUP BY 1, 2 ORDER BY 1, 3 DESC
```

Tokens per ticket, per harness:

```sql
SELECT ticket, COALESCE(agent, 'claude-code (proxy)') AS harness, count(DISTINCT trace_id)::BIGINT AS traces, sum(COALESCE(tokens_prompt, 0) + COALESCE(tokens_completion, 0))::BIGINT AS tokens FROM spans WHERE ticket IS NOT NULL GROUP BY 1, 2 ORDER BY 4 DESC LIMIT 20
```
